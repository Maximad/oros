# أصوات سوا — Óros

موقع عربي RTL بسيط لمشروع «أصوات سوا» بالشراكة بين جوقة Óros وحبق ناس.

## الهدف

تحويل مخرجات ورش الغناء والتسجيلات الكورالية إلى مكتبة مجتمعية سهلة الاستخدام على الهاتف، بحيث يستطيع الزائر:

- استعراض الأغاني والمقاطع.
- تعلّم كل دور صوتي بشكل منفصل.
- الاستماع إلى النسخة الجماعية ونسخ التدريب.
- الاطلاع على مقاطع مختارة من الورش بعد الموافقة على النشر.
- إرسال مساهمة صوتية لاحقاً بعد ربط نموذج رفع آمن.

## الحالة الحالية

هذه نسخة أولية front-end فقط. لا توجد تسجيلات أو رفع ملفات حقيقي حتى الآن، ولم يتم اختراع أسماء للأغاني قبل تثبيت الريبرتوار.

## الملفات

- `index.html` — الصفحة الرئيسية.
- `styles.css` — التصميم المتجاوب وRTL.
- `script.js` — بيانات الأغاني التجريبية وتفاعل الواجهة.

## النشر

المشروع static ويمكن نشره مباشرة عبر GitHub Pages أو أي استضافة static. عند إضافة ملفات الصوت يفضّل وضعها داخل `assets/audio/` أو استخدام تخزين خارجي إذا أصبحت الأحجام كبيرة.

## الخطوات التالية

1. تثبيت أسماء الأغاني الأربع والمواد التدريبية.
2. إضافة شعار Óros وهوية حبق ناس.
3. إضافة ملفات الصوت لكل دور والنسخ الجماعية.
4. ربط نموذج المساهمات بخدمة رفع آمنة وموافقة واضحة على النشر.
5. إضافة سياسة خصوصية مختصرة وإجراء سحب المحتوى عند الطلب.
