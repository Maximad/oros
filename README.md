# أصواتنا سوا — Óros

موقع عربي RTL لمشروع «أصواتنا سوا» لجوقة Óros، بإنتاج حبق ناس وبدعم من مؤسسة العمل للأمل.

## الهدف

تحويل تسجيلات Óros إلى مكتبة تدريب كورالي مجتمعية يستطيع الزائر من خلالها:

- اختيار الأغنية والطبقة الصوتية.
- الاستماع إلى دور السوبرانو أو الألتو أو التينور أو الباس منفردًا.
- التدريب على مقاطع قصيرة بحسب الجمل الموسيقية ومواقع التنفّس.
- تسجيل محاولة مباشرة من المتصفح والاستماع إليها منفردة أو داخل الكورال.
- حفظ التسجيل اختياريًا ضمن أرشيف المشروع بعد موافقة صريحة.
- تصفح صور المشروع والتسجيلات المحفوظة.

## المحتوى الحالي

الأغنيتان المتاحتان:

- «وصلة تراثية».
- «ديرتي».

لكل أغنية أربعة مسارات SATB:

- سوبرانو
- ألتو
- تينور
- باس

## البنية

- `index.html` — الصفحة الرئيسية.
- `script.js` — بطاقات الأغاني وفتح مساحة التدريب.
- `choir-training-data.js` — الطبقات، المقاطع، الأزمنة والكلمات.
- `choir-player-v2.js` — مشغّل التدريب والتسجيل والمقارنة.
- `recordings.js` / `recordings.html` — حفظ التسجيلات وعرض الأرشيف.
- `api/recordings/` — API بسيط بـ PHP لحفظ التسجيلات وبياناتها.
- `recordings-data/` — تخزين التسجيلات على الخادم، ويجب عدم استبداله أثناء النشر.

## الوسائط

الوسائط الدائمة موجودة على الاستضافة تحت:

- `aswat/assets/`
- `aswat/recordings-data/`

ويجب الحفاظ على المجلدين خارج أي عملية استبدال للكود.

## النشر على Hostinger

GitHub `main` ينشر تلقائيًا إلى بيئة المعاينة:

`public_html/oros`

بعد التحقق من المعاينة، تُنقل ملفات الكود إلى الموقع الحي:

`public_html/aswat`

باستخدام:

```bash
bash ~/domains/habaq.online/public_html/oros/deploy-live.sh
```

السكريبت يحفظ نسخة احتياطية من الكود الحالي، وينقل النسخة الجديدة، ولا يلمس `assets/` أو `recordings-data/`.

الموقع الحي:

`https://aswat.habaq.online`
