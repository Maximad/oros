# أصواتنا سوا — Óros

موقع عربي RTL لمشروع «أصواتنا سوا» لجوقة Óros، بإنتاج حبق ناس وبدعم من مؤسسة العمل للأمل.

## الهدف

تحويل التسجيلات الكورالية ومواد التدريب والورش إلى مكتبة مجتمعية سهلة الاستخدام، بحيث يستطيع الزائر:

- استعراض الأغاني.
- تعلّم كل دور صوتي بشكل منفصل.
- استخدام المسارات في التدريب الفردي والجماعي.
- الاطلاع على صور المشروع.
- المشاركة بصوت أو فيديو لاحقاً بعد تفعيل نموذج رفع آمن.

## المحتوى الحالي

تضم المكتبة أغنيتين:

- «وصلة تراثية».
- «ديرتي».

لكل أغنية ستة مسارات صوتية منفصلة.

## الملفات

- `index.html` — الصفحة الرئيسية.
- `styles.css` — التصميم الأساسي المتجاوب وRTL.
- `enhancements.css` — الهوية البصرية، الخط، الصور، الشركاء والتحسينات المتجاوبة.
- `script.js` — بيانات الأغاني وتشغيل مسارات التدريب.

## الوسائط

تُستضاف ملفات الصوت والصور والشعارات والخطوط على `aswat.habaq.online`، بينما يبقى الكود في هذا المستودع.

## النشر

يمكن معاينة المشروع عبر GitHub Pages، ثم نشر النسخة النهائية على `aswat.habaq.online` عبر Hostinger.
